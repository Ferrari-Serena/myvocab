🚀 使用说明

需通过 HTTP 服务器访问（应用使用 ES 模块，file:// 协议无法加载）。
在项目根目录运行：node server.js，然后访问 http://localhost:5173/tasks2/

开发模式（修改源码时使用）：
蚕食：cd tasks2/vocabulary && npm run dev → http://localhost:2000
Word Wind：cd tasks2/word-wind && npm run dev → http://localhost:5173

修改源码后需重新构建：
cd tasks2/vocabulary && npm run build（输出到 docs/）
cd tasks2/word-wind && npm run build（输出到 dist/）
